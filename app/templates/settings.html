Setup Guide

Option A: IMAP Access (Recommended)

If your organisation allows IMAP access, this is the easiest way to connect.

  1. Check if IMAP is enabled: Go to Outlook Settings → Mail → Sync email → POP and IMAP
  2. If enabled, set the following environment variables in your .env file: 
    EA_IMAP_HOST=outlook.office365.com
EA_IMAP_PORT=993
EA_IMAP_USER=your-email@company.com
EA_IMAP_PASSWORD=your-password-or-app-password
EA_SMTP_HOST=smtp-mail.outlook.com
EA_SMTP_PORT=587
  3. If your organisation requires MFA, you may need to create an App Password:
    Go to Microsoft Security Info → Add sign-in method → App password
  4. Restart the assistant after saving the .env file

Option B: Email Forwarding (No Admin Needed)

If IMAP is blocked, you can forward emails to the assistant's webhook.

  1. In Outlook, go to Settings → Mail → Rules
  2. Create a new rule:
    • Condition: Apply to all messages
    • Action: Forward / redirect to a processing email or use the webhook URL below
  3. The assistant will automatically process forwarded emails

Webhook URL: http://localhost:8000/api/webhook/ingest

Option C: Manual Upload

Export emails from Outlook as .eml or .msg files and upload them via the API.

  1. In Outlook, select emails → File → Save As → Save as .eml
  2. Place the files in the data/imports folder
  3. Use the import API endpoint to process them

AI Configuration

The assistant uses Azure AI for email summarisation and drafting. Set these in .env:

EA_AZURE_AI_ENDPOINT=your-azure-endpoint
EA_AZURE_AI_KEY=your-azure-api-key
EA_AZURE_AI_MODEL=gpt-4o

Storage Tips

Freeing Outlook Storage

  1. Back up first: Use the "Backup Now" button on the Dashboard to save all emails locally
  2. Empty Deleted Items: In Outlook, right-click "Deleted Items" → Empty Folder
  3. Clear Sent Items: Old sent emails often consume significant space
  4. Junk Email: Empty your Junk Email folder
  5. Large attachments: Sort by size and delete emails with large attachments (after backing up)
  6. Archive policy: Set up the assistant to auto-backup emails older than 30 days, then safely delete them from Outlook
